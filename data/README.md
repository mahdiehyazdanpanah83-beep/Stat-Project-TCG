# Data Directory

Raw and heavy data files are intentionally excluded from git version control via `.gitignore`.

### Required Datasets:
Please place the following raw files into this directory:
- `clinical.tsv`
- `follow_up.tsv`
- `tcga_brca_clinical_core_aligned.csv`
- `tcga_brca_survival_final.csv`

Data source: TCGA BRCA project via GDC Data Portal / cBioPortal.
